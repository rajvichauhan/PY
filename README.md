## 🎵 Music Player Project in Python

A feature-rich **Music Player** built using **Python**, with a database-driven backend for managing songs. This project allows users to play, pause, and manage music files while storing song details in a **local database**.  

### 🔹 Features  
- **Play, Pause, Stop Controls** – Seamless music playback.  
- **Database Integration** – Uses a **local MySQL database** to store song details.  
- **Song Management** – Add, remove, and browse songs from the database.  
- **User-Friendly UI** – Simple and interactive interface.  

### 🚀 Technologies Used  
- **Python Libraries:** Tkinter, Pygame (for audio playback), MySQL Connector.  
- **Database:** MySQL (SQL file included in the repo).  

### 📌 Setup Instructions  
1. **Install Dependencies**  
   ```sh
   pip install pygame mysql-connector-python
   ```
2. **Set Up the Database**  
   - Import the SQL file (`newmusic.sql`) into MySQL.  
   - Update database credentials in the code if necessary.  
3. **Run the Application**  
   ```sh
   python music_player_app.py
   ```

### ⚠️ Note  
- This project requires a **local MySQL database**. Ensure MySQL is installed and running.  
- The **SQL file (`database.sql`)** is included in the repository for easy setup.
